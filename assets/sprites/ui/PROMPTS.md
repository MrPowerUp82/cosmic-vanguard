# Prompts de geração

Modo: ferramenta integrada image_gen, transparência solicitada e canal alfa verificado. Os originais foram copiados para o projeto sem alterar os pixels. As coordenadas do atlas foram ajustadas à composição efetivamente gerada, que não segue uma grade uniforme.

## HUD

Use case: stylized-concept. Asset type: production game HUD sprite atlas for Cosmic Vanguard, a sci-fi superhero arcade beat-em-up. Generate one transparent PNG sprite sheet, 1536x1024 landscape, organized in exactly 4 columns by 4 rows of equal 384x256 cells. Each cell contains ONE centered isolated complete asset, maximum 340x200 px, with ample transparent gutters. No words, letters, numbers, labels, grid lines or background. Sharp illustrated arcade game art, steel navy bevels, crisp cyan luminous edges, gold accents, restrained glow, readable at small scale, orthographic front view. Row 1 left to right: empty horizontal health bar metal frame (wide and thin); empty horizontal energy bar metal frame (wide and thin); solid red health fill strip without frame; solid cyan energy fill strip without frame. Row 2: empty square portrait frame with transparent center; gold credit coin icon with star emblem; cyan lightning bolt special power icon; gold shield icon. Row 3: cyan attack fist icon; cyan wing mobility icon; white upward jump arrow icon; gold circular two-arrow hero swap icon. Row 4: small circular pause button with two vertical bars; empty horizontal purple boss health frame; solid purple boss fill strip without frame; cyan right-facing proceed chevron. Transparent background with actual alpha, no shadows outside sprites, no UI mockup or scenery. Every sprite separated and completely inside its own cell.

## Menu

Use case: stylized-concept. Asset type: production menu UI sprite atlas for Cosmic Vanguard sci-fi superhero arcade game. One transparent PNG sprite sheet, 1536x1024 landscape, exactly 4 columns and 4 rows of equal 384x256 cells. ONE isolated centered asset per cell, all within their cell with transparent gutters. Crisp comic-book arcade illustration, beveled navy steel panels, cyan luminous edges, gold highlights, same cohesive futuristic superhero interface style. Front view, flat orthographic usable interface assets. No words, letters, numbers, captions, watermark, grid, scenery or backdrop. Row 1: wide empty rectangular button normal navy and cyan; same button selected with gold border; same button pressed darker inset cyan; same button disabled desaturated steel. Each button width about 330px height about 100px, identical silhouette and empty dark center for code-rendered text. Row 2: empty wide save-slot card normal cyan border; same card selected gold border; same card locked dull steel border; empty wide dark modal panel cyan frame. Row 3: empty square hero-card frame normal cyan; same hero-card frame selected gold; same hero-card locked frame gray; isolated gold padlock icon. Row 4: cyan right pointing triangular play icon; cyan gear settings icon; cyan left pointing back arrow icon; red close X icon. All items have hard clean edges and minimal glow contained inside their cells. True transparent alpha background outside each individual sprite; transparent holes inside hero frames; dark opaque interiors of buttons/cards/modal. No checkerboard baked in, no atmospheric light/background.
