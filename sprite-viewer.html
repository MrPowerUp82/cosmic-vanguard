Como recortar
  1. Clique em Analisar para detectar os sprites automaticamente.
  2. Faltou algum? Arraste um retângulo em volta dele — a caixa encaixa sozinha no desenho.
  3. Ajuste: arraste as alças amarelas, o pivô vermelho (pés) ou use as setas.
  4. Use Duplicar → (Ctrl+D) para criar o próximo frame de uma sequência.
  5. Roda do mouse dá zoom, Espaço+arrastar move a vista. ? mostra todos os atalhos.
